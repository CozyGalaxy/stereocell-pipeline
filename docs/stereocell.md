## 1. 技术特点

Stereo-cell（Science, 2025-08-22）：细胞悬液直接平铺到 DNB 芯片（220 nm 球、500 nm 间距），静电吸附原位捕获，无需液滴分隔；百至百万级细胞通量；多模态（形态+转录本+表面蛋白）；支持原位培养动态测序。**主动增强 RNA 扩散以提高单细胞捕获量**。

与组织 Stereo-seq 的算法相关差异：
- 细胞分布稀疏（点过程），核分割容易，仅聚集团块难；
- RNA 扩散是**有意引入**的 → 要建模利用，不是单纯消除；
- 大片空白 DNB = 天然背景 → 环境 RNA 谱和扩散核估计极为有利（组织 Stereo-seq 做不到）；
- 主要误差：聚集细胞互染 + 扩散分子跨细胞归属。

## 2. 推荐算法：种子 + 密度自适应归属

```
1. seeds: ssDNA 核分割（Cellpose-SAM / CellBin 核模型；稀疏场景经典 watershed 即可）
2. d_i  = 核质心 1-NN 距离；D_ISO = 6×核半径中位数；d_i > D_ISO 记为孤立细胞
3. 扩散长度估计: 孤立细胞径向 UMI 衰减拟合 exp(-r/λ) → r95 = λ·ln20
4. 逐细胞基因谱 π_i 用核内分子初始化
5. GMM-EM 归属（候选 = r95 内所有细胞 + 空间均匀背景类）:
   E: p(m→i) ∝ N(x_m; c_i, σ²I)·π_i(gene_m)；背景 b(gene)/Area
   M: 更新 π_i
6. 归属接受规则（"缩小扩散因子"的正确实现）:
   keep ⟺ conf > 0.55 且 conf > P(背景) 且 conf − 第二候选后验 > 0.20
   → 聚集区中线上模糊分子被整体拒收, 而不是硬划给某一边
7. 输出: cell×gene 矩阵 + 分子置信度层; 多核团块标记 multiplet 候选
```

配套：用空白区估计逐基因背景谱；高扩散基因（SpotGF 式最优传输）在归属证据中降权。

## 3. 关键工程教训（模拟原型实测，420 细胞含 60 聚集对，σ_d=14 px）

| 方法 | 捕获率 | 总体污染 | 近邻分子污染 |
|---|---|---|---|
| 固定半径最近中心（基线） | 0.893 | 0.076 | 0.229 |
| 硬领地截断 EM（R_i=min(r95, 0.9·d/2)） | 0.694 | 0.035 | 0.262 |
| **后验边际拒绝 EM** | **0.900** | 0.058 | **0.177** |

- **不要把领地硬性截断到中线以内**：细胞自己的扩散分子会越过截断边界落入邻细胞领地，污染反而升高；同型紧贴细胞对的几何污染下限 ≈ 1−Φ(d/2σ)，硬截断同时损失大量捕获。
- **"距离近缩小扩散因子"的正确实现是后验边际拒绝**（top1−top2 后验差阈值），而非缩小候选半径：拥挤处模糊分子拒收，孤立细胞充分外扩，捕获率与污染率同时优于基线。
- 背景类必须带空间均匀密度项（1/Area），否则量级压倒高斯似然，全部误拒。
- 同型紧贴细胞对存在不可约污染；此时应输出低置信标记供下游过滤，而非强行归属。

原型脚本：scripts/stereocell_adaptive_em.py（模拟数据生成 + 三方法对比 + QC 图）。

## 4. 验证方案

- λ 估计稳定性：孤立细胞径向衰减曲线按区域分层检查；
- 按 d_i 分层统计跨细胞 marker 互染率，确认拥挤区污染下降且总 UMI 损失可控；
- 模拟基准：估计核 + 真实核位置合成已知真值数据，比较细胞×基因矩阵余弦与 doublet 率；
- 端到端：细胞类型比例 vs 流式/液滴法参考（Stereo-cell 论文 PBMC 范式）。
