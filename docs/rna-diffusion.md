## 1. 机制与影响

透化过程中 mRNA 从释放点横向扩散，被邻近捕获点（DNB/spot/bead）捕获 → spot swapping。后果：
- 表达边界模糊，marker 基因空间特异性下降；
- 细胞边界附近分子错分（CellBin/分割直接受害）；
- 空间差异分析、配体-受体互作等边界敏感分析假阳性升高。

扩散程度取决于：平台化学、组织类型、透化时间、切片厚度与固定质量。**实验端优化（透化时间梯度、固定）永远优先于计算补救。**

## 2. 现有校正方法对比

| 方法 | 思路 | 平台限制 | 注意事项 |
|---|---|---|---|
| SpotClean (Nat Commun 2022) | 概率模型分解原位/交换计数，用组织外背景 spot 估计污染谱 | 仅 Visium 类（需背景 barcode + 明确 spot 边界）；**不适用 Stereo-seq/Slide-seq** | 不保原始计数（可能扭曲生物学）；主要提升 marker 特异性与 DE 功效，聚类结构变化小 |
| SpaDiff (2025) | 把扩散建模为布朗运动，扩散模型前向加噪/逆向去噪，score 函数把分子"推回"高密度原位 | 通用（2D 表达图即可） | 非参数、保计数、鲁棒；新方法，需在自家数据验证 |
| SpotGF / GF | 最优传输估计逐基因扩散潜力，**过滤高扩散基因** | 通用 | 不改计数；适合 marker/下游分析前基因筛选 |
| SoupX / DecontX | scRNA 环境 RNA 校正（基于聚类） | 不适合空间数据 | 无空间依赖建模，ST 上反而增加假发现——勿套用 |
| 平滑类（Sprod、图平滑等） | 邻域/图平滑降噪 | 通用 | 进一步模糊边界，边界敏感分析禁用 |

综述现状（2025）：**Stereo-seq 与 Slide-seq 尚无专用 spot-swapping 校正工具**——这是算法研发空缺点。

## 3. 面向 Stereo-seq / CellBin 的优化策略

按实施成本排序：

1. **扩散量化（先做）**：用组织外背景 DNB/bin 的逐基因 UMI 分布估计扩散核（SpotClean 背景建模思想的 Stereo-seq 改造）；输出逐基因 bleeding index。高扩散基因在边界判定与 marker 分析中降权（SpotGF 思路）。
2. **分割前锐化**：对 bin 级表达图做 SpaDiff 式逆向扩散，或估计 PSF 后做 Wiener / Lucy–Richardson 反卷积，再进 CellBin/第三方分割。注意只在 bin 图层面做，cellbin 结果由分割重新汇聚。
3. **边界分子概率化归属**：CellBin MLCG（GMM）与 Baysor（MRF）结合——核 mask 强先验 + 边界分子后验分配 + 置信度输出；低置信分子剔除或单独成层，不进 cellbin 主矩阵。
4. **图像-表达互证 QC**：核内 UMI 占比、相邻细胞 marker 互污染率作为样本级指标；超标时自动降级 bin 尺寸或启用去噪分支。
5. **分割算法层面**：用 ssDNA 核 mask 约束 Voronoi/流域的最大外扩范围，使扩散分子无法跨核归属——相当于给表达驱动的边界一个形态学上界。

## 4. 评估方案

- **金标准**：人鼠嵌合样本（人源转录本落入鼠区比例 = 扩散+串扰率）；已知解剖边界的 marker 空间特异性。
- **合成基准**：把 Xenium 等分子级数据按六角 spot 聚合模拟 Visium，注入不同强度布朗扩散，比较去噪后与真值的 Jensen–Shannon 散度（SpaDiff 论文范式）。
- **端到端**：去噪前后聚类 ARI（对有注释数据）、DE 基因功效、配体-受体结果稳定性（STopover 论文用 SpotClean 前后相关性 R≈0.6 论证稳健性的范式）。
- **分割侧**：同一组织校正前后跑相同分割流程，比较边界分子低置信比例与核内 UMI 占比变化。
